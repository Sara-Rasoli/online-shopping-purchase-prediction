# Online Shopping Behaviour Analysis and Purchase Intention Prediction

## Overview

This project explores online shopping session data to better understand customer behaviour and identify patterns associated with purchasing decisions.

The project focuses on preparing e-commerce data for machine learning, exploring relationships between customer behaviour features, and developing an analytical foundation for customer segmentation and purchase intention prediction.

## Objectives

- Explore online shopping session data and identify behavioural patterns.
- Clean and preprocess data for machine learning.
- Handle missing values, duplicate records, and outliers.
- Apply encoding and feature scaling where appropriate.
- Explore supervised and unsupervised machine learning approaches.
- Investigate how browsing activity and engagement relate to purchase behaviour.

## Dataset

The project uses the **Online Shoppers Purchasing Intention Dataset** from the UCI Machine Learning Repository.

The dataset contains session-level information, including page visits, browsing duration, bounce rates, exit rates, visitor type, and purchase outcomes.

Dataset source: https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset

## Project Workflow

1. **Data understanding:** Examine dataset structure, feature types, and descriptive statistics.
2. **Exploratory data analysis:** Investigate feature distributions, relationships, and correlations.
3. **Data preprocessing:** Handle missing values, duplicate records, and outliers.
4. **Feature preparation:** Encode categorical variables and scale numerical features as appropriate.
5. **Machine learning preparation:** Prepare separate data pipelines for supervised prediction and unsupervised clustering.
